# الموقع الشخصي — حسين عبدالله أبو زيد

موقع شخصي عربي RTL بتصميم أسود وذهبي، متجاوب مع الهاتف والكمبيوتر، وبدون موسيقى. يتضمن اللغات العربية والإنجليزية والألمانية واهتمامات الهاردوير والسوفتوير والبرمجة.

## تخصيص الموقع
- `index.html`: الاسم، النبذة، اللغات، المجالات التقنية، صور المعرض وروابط الحسابات.
- `style.css`: الألوان والتصميم والتجاوب.
- `script.js`: قائمة الهاتف والتنبيه للروابط التي لم يتم تخصيصها.
- `assets/`: الصور المؤقتة. استبدلها بصورك، ثم عدّل المسارات في `index.html` إذا غيّرت أسماء الملفات.

مستويات الإنجليزية والألمانية غير محددة في الموقع؛ عدّلها فقط حسب مستواك الحقيقي. كما أن مجالات التقنية معروضة كاهتمامات، ويمكنك تعديلها لتعكس خبرتك الفعلية.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا في https://github.com باسم `hussein-personal-site`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع بحيث يكون `index.html` في الجذر.
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch**، ثم `main` و`/(root)` واضغط **Save**.
5. انتظر النشر. سيظهر الرابط في صفحة Pages، عادةً: `https://YOUR-USERNAME.github.io/hussein-personal-site/`.

الاستضافة على GitHub Pages مجانية للمواقع الثابتة. لا تضع معلومات خاصة في مستودع عام.
